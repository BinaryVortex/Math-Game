# Math-Game

![Screenshot](./Screenshot%202024-08-25%20183428.png)

Math-Game is a small, browser-based game built with plain HTML, CSS, and JavaScript. It's designed to help players practice basic arithmetic in a fun, interactive way.

## Features

- Clean, responsive UI built with HTML & CSS
- Pure JavaScript game logic (no frameworks)
- Randomized arithmetic problems (addition, subtraction, multiplication, division)
- Score tracking and simple feedback
- Easy to run locally — no build step required

## Demo / Screenshot

The screenshot above shows the game's UI and gameplay elements.

## How to run

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Math-Game.git

2. Open `index.html` in your web browser (double-click the file or serve it with a static server).

That's it — the game runs entirely in the browser.

## Usage

- Choose the difficulty or mode (if available in the UI).
- Answer the arithmetic questions as they appear.
- The game keeps score and gives immediate feedback for correct/incorrect answers.

## Development

- The project uses plain JavaScript, CSS, and HTML. Files to look at:
  - `index.html` — main HTML layout
  - `style.css` — styles for the UI
  - `script.js` — game logic

- To modify the game, edit `script.js` and refresh your browser.
